# AlphaArena 🏆 — Global Trading Tournament & Competition Aggregator

**AlphaArena** is a directory and discovery platform that aggregates live, upcoming, and ended trading competitions and tournaments across crypto exchanges, forex brokers, prop firms, and offline trading championships.

---

## ✨ Features

- **🔴 Live Tournament Feed**: Real-time status indicators, dynamic countdown timers, entry fees, and verified prize pool tracking ($3.2M+ aggregated).
- **🎯 Multi-Market Coverage**:
  - **Crypto Exchanges**: Binance, Bybit, OKX, Bitget, BingX, KuCoin
  - **Forex Brokers & Championships**: World Cup Trading Championships, XM, Exness
  - **Prop Firm Challenges**: FTMO, FundedNext, The Funded Trader, Funding Pips
- **🔍 Fast Instant Search & Filters (⌘K / Ctrl+K)**:
  - Filter by market type (Crypto, Forex, Prop Firm, Stocks, Futures)
  - Filter by entry cost (Free-to-Enter vs Paid Challenge)
  - Filter by status (Live Now, Starting Soon, Registration Open, Ended)
  - Filter by prize pool size ($100k+, $500k+, $1M+) and country eligibility
- **🤖 Built-in AI Trading Assistant (Claude-Powered Copilot)**:
  - Answers tournament eligibility questions, compares competition rules side-by-side, explains ROI calculations vs drawdown rules, and searches database with tool calling.
- **📊 Terminal & Esports Design System**:
  - High-octane arena dark theme with neon orange and purple accents.
  - Responsive layout for desktop and mobile traders.
- **🏛️ Hall of Fame & Past Results Archive**:
  - Leaderboard records, past championship winners, and historical winning ROIs.
- **📝 Tournament Submission & Admin Moderation**:
  - Self-serve submission form for platform organizers with admin dashboard.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **AI Engine**: Claude API integration with agentic tool calling (`search_competitions`, `get_competition_details`)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed

### Installation

1. Clone the repository:
```bash
git clone https://github.com/guptaextd/trading-tournament.git
cd trading-tournament
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open your browser and navigate to:
```
http://localhost:3000
```
